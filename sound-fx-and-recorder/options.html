Settings / 設定

DSP + WAV / WebM·Opus

FX / エフェクト

Choose how the gadget starts when POWER is turned on.
POWERをONにしたときのエフェクト初期状態を設定します。

Startup effect level 起動時のエフェクト量
50

With Last used, BYPASS is remembered too. If POWER starts in BYPASS, turning BYPASS off goes to WIDE. When per-mode memory is disabled, every mode starts at the Startup effect level.
前回のモードではBYPASSも記憶します。BYPASSで起動した場合、BYPASSを解除するとWIDEになります。モード別記憶をOFFにすると、各モードは「起動時のエフェクト量」から開始します。

Download name / ダウンロード名

Choose the parts used for the recording filename.
録音ファイル名に使う要素を選択します。

Example / 保存例 [Tab title here].wav

Duplicate names are automatically uniquified, e.g. file (1).wav or file (1).webm.
同名ファイルは自動で重複を回避します。

Recording / 録音

Select a format for the next recording. Playback remains stereo in all modes.
次回の録音形式を選択します。再生音声はどの形式でもステレオのままです。

Silence trim applies to WAV and both Opus formats. Pauses inside the recording are kept. Opus is analyzed after STOP and trimmed without re-encoding; FX continues during saving. If trimming fails, the original recording is saved with a warning.
無音トリムはWAV・Opus共通です。録音途中の無音は残します。OpusはSTOP後に解析し、再エンコードせずに前後を切り出します。保存中もFXは継続し、トリム失敗時は警告を表示して録音全体を保存します。

The 10-minute limit is optional for WAV and is never used for Opus. Opus uses on-disk temporary chunks to keep RAM usage low; the temporary file is removed after Chrome finishes downloading. WAV still accumulates PCM in memory, so long WAV recordings can use substantial RAM.
10分自動停止はWAVのみの任意設定で、Opusには適用されません。Opusは圧縮データを一時ディスクへ逐次書き込み、ダウンロード完了後に削除します。WAVは従来どおりPCMをメモリに蓄積します。

REC always records the currently audible signal. BYPASS is never switched automatically. With BYPASS on, the original tab audio is recorded; otherwise the current FX/EQ is included.
RECは常に現在の出力音を録音します。BYPASSは自動で切り替えません。BYPASS中は原音、それ以外はFX/EQ適用後の音を保存します。

● Changes are saved automatically. / 変更は自動保存されます。
