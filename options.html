FX / エフェクト

Choose how the gadget starts when POWER is turned on.
POWERをONにしたときのエフェクト初期状態を設定します。

Startup effect level 起動時のエフェクト量
50

With Last used, BYPASS is remembered too. If POWER starts in BYPASS, turning BYPASS off goes to WIDE. When per-mode memory is disabled, every mode starts at the Startup effect level.
前回のモードではBYPASSも記憶します。BYPASSで起動した場合、BYPASSを解除するとWIDEになります。モード別記憶をOFFにすると、各モードは「起動時のエフェクト量」から開始します。

Choose the parts used for the saved WAV filename.
保存するWAVファイル名に使う要素を選択します。

Duplicate filenames are automatically uniquified, for example file (1).wav.
同名ファイルがある場合は file (1).wav のように自動で重複を回避します。

Recording / 録音

Recording captures the current output, including WIDE / SURROUND / ROOM / HALL, or the clean tab audio while BYPASS is active. Silence detection runs after the selected signal path, so reverb tails are preserved when they remain above the threshold.
録音は現在の出力をそのまま保存します。WIDE / SURROUND / ROOM / HALLの加工音だけでなく、BYPASS時は原音のまま録音できます。無音判定も現在の出力に対して行うため、残響がしきい値を上回る間はリバーブテールも保存されます。

● Changes are saved automatically. / 変更は自動保存されます。
